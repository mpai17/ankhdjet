Between-Layer Requantize / no buffer

Layer 1 hands its raw integer accumulators straight to Layer 2 as low-bit activations, through one stateless combinational step per channel: multiply by the tensor scale, arithmetic-shift, ReLU, saturate. No clock, no register, no SRAM sits between the two tiles.

act[c] = clip( ReLU( ( acc[c] × sq ) >> Q ) , 0 , 2K−1 )   // sq=128 (scale 0.5, Q8.8), Q=8, K=8 → range 0..255

Rescale in fixed point

The wide signed accumulator is multiplied by the per-tensor scale sq and arithmetic-shifted right by Q, folding dequant and requant into one integer op.

ReLU clamps negatives

Anything below zero becomes 0, which is the layer's nonlinearity, applied right here in the same combinational path.

Saturating clip

The result is clipped to the K-bit unsigned range 0..255, so large accumulators saturate into the next layer's activation width.

How this differs from a full BitNet forward pass

The scale-and-shift and the saturating clip are faithful: BitNet's W1.58A8 inference dequantizes each accumulator by the weight-and-activation scale and re-quantizes activations to a fixed integer range with saturation. Two things here are simplified. The ReLU stands in for the layer's real nonlinearity (BitNet's FFN uses squared-ReLU or a gated variant, and an RMSNorm precedes the quantized linear, neither shown here). And the scale is a static per-tensor constant in this example, whereas real BitNet recomputes a per-token activation scale dynamically. So the mechanism is exact; the specific activation and the dynamic scale are where it diverges from a real forward pass.
